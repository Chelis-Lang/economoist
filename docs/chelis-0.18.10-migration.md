# Chelis 0.18.10 migration

Economoist 0.2.13 participates in the compiler-compatible C Note dependency
release wave for Chelis 0.18.10 (the 2026-09-15 wave). It uses the published
compiler; no compiler source build or local compiler patch is required. This
shell moves from 0.18.9 to 0.18.10 with no functional change.

Chelis 0.18.10 is a corrective release over 0.18.9: it fixes the two 0.18.9
regressions (Chelis-Lang/chelis#2059, interpreter evaluation performance, and
Chelis-Lang/chelis#2068, native-C airy/ownership). Economoist never carried a
perf or suite-timeout bandaid for those regressions, so there is nothing to
revert here; the fixes simply confirm that no such bandaid is needed at this
pin.

The compiler tag resolves to `b9095ccf2c0b76859aa447c6febe699fd287f1d2`
(annotated tag object `e247a5d33cd2df552f57e3efddfd4ea30846b3b8`, tag
`v0.18.10`). The sidecar-verified Linux glibc-2.31 archive SHA256 is
`0843697e0a7783e383df0347ae431ae56f62b5a5ae34a7aa72ac37ee91df1e0b`;
the compiler payload SHA256 is
`6622e40bc786c562b5b66d370a84e46ded551dee70abfc617a71d026c0119b00`.
These fields come from the published v0.18.10 release (release run
34966582543). The darwin-arm64 archive used for the local gate on this
workstation is
`80c9c5b42a8fbcee6884915df1a4dafb8bcc1cae33199ded060d8b2ebece8bf0`; its
`bin/chelis` payload SHA256 is
`a6af380886b21761bc2822a814e4fef4232e8b8551922d32bca722cd4e04e1e2`.

This is a rebuild, not a repair. No model body, precondition, numeric golden
or expected tier is weakened. No new public function needs a two-configuration
acceptance case. The `properties/` unqualified-SMT-green boundary and the
separate `sampled/` fuzz lane are unchanged.

The offline gates ran at this pin: the manifest consistency gate
(`scripts/contract_gate.py`) and the pin guard
(`scripts/audit_workarounds.py --pins-only`), plus the mechanized conformance
audit (`chelis reef conform audit`, conformant: no MUST failures). `reef.lock`
was regenerated by `chelis reef build` under the published 0.18.10 compiler;
only the compiler pin, the package version, and the bundled chelis-std archive
and shell hashes changed. The complete ten-stage local gate (formatting, lint,
package build, native tests, negative and blocked adapters, manifest
consistency, SMT proof and controls, anti-vacuity forges, and numerical
oracles) ran against the released 0.18.10 darwin-arm64 binary and is green.
Nine invariants retain the `proven` expectation and one concrete f32
sensitivity retains `fuzz_validated`.

The parked Beacon capability and the archived language issues carry over from
the 0.18.9 migration unchanged; there is no active language workaround to
retire here.

  `.github/actions/install-chelis` step of the `Chelis gate` job on the release
  PR against [Chelis-Lang/economoist](https://github.com/Chelis-Lang/economoist).
