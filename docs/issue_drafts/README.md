# Issue Drafts

Ready-to-file upstream issue drafts, parked here until the filing condition is
met. Cite by path (`docs/issue_drafts/<name>.md`) at narrowing sites and in
`UPSTREAM_BUGS.md` until filed upstream as `chelis#NNN`, then replace the path
citation with the issue number.

Before filing, search the `Chelis-Lang/chelis` tracker by symptom keywords to
avoid a duplicate.

| Draft | Filing condition |
|---|---|
| `smt_in_release_tarball.md` | Confirm the released tarball still lacks the `smt` feature at the next release. |
| `eval_side_import_resolution.md` | Confirm eval still does not resolve standalone-file imports when a C Note template needs it. |
| `scalar_max_abs_f32.md` | Confirm no scalar `f32` max/min/abs lands in chelis-std at the next release. |
